# Theme and Localization

## Design Tokens
- Colors: `AppColors`
- Spacing: `AppSpacing` (xxs to huge)
- Radii: `AppRadii` (xs to full)
- Typography: `AppTextStyles`
- Themes: `AppThemeData.lightTheme` & `AppThemeData.darkTheme`

## Localization Setup
- Arabic (Default, RTL): `lib/l10n/app_ar.arb`
- English (Secondary, LTR): `lib/l10n/app_en.arb`
- Generation Command:
  ```bash
  flutter gen-l10n
  ```
